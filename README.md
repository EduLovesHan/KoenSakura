# 🌸 KoenSakura - 3D Virtual Tour

## Abstract
This project is an interactive 3D virtual tour set in Japanese-style parks, developed in JavaScript using Three.js (WebGL). It allows users to explore a low-poly 3D environment, simulating an immersive visit with interactions, dynamic lighting, and sound, optimized for a seamless web browser experience.

**Live Demo:** [koen-sakura.vercel.app](https://koen-sakura.vercel.app/)

## Key Features
* First-person interactive tour.
* Responsive navigation controls (WASD/Joystick).
* Dynamic interactions with 3D models.
* Intuitive user interface.
* Cross-platform support (runs natively on modern web browsers).

## Keywords
JavaScript, Three.js, WebGL, Vite, virtual tour, 3D, computer graphics, simulation, interactive environment, frontend.

## Minimum System Requirements
Since this is a WebGL-based application, performance relies on using a modern web browser with 3D graphics support.

**PC:**
* **OS:** Windows 10 / macOS 10.14 or higher.
* **Browser:** Any modern browser with WebGL support enabled (Chrome, Firefox, Edge, Brave, Opera, etc.).
* **RAM:** 4 GB minimum (8 GB recommended).
* **Graphics:** Intel UHD Graphics or dedicated GPU with WebGL 2.0 support.

**Mobile:**
* **OS:** Android 10.0+ / iOS 14.0+
* **Browser:** Any modern mobile browser compatible with WebGL (Chrome, Safari, Brave, Opera Mobile, etc.).
* **RAM:** 3 GB minimum (4 GB or more recommended).
* **Graphics:** Modern mobile GPU.

## How to Clone this Repository

To get a local copy of the project, run in your terminal:
```bash
git clone [https://github.com/EduLovesHan/KoenSakura.git](https://github.com/EduLovesHan/KoenSakura.git)


```

Navigate to the project directory:

```bash
cd KoenSakura


```

## Install Dependencies

First, make sure you have [Node.js](https://nodejs.org/) installed on your computer.
Restore dependencies using npm by running:

```bash
npm install


```

## Build and Run

To start the local development server:

```bash
npm run dev


```

Click on the local link provided in the terminal (usually `http://localhost:5173/`).

To build the project for production:

```bash
npm run build


```
