# KoenSakura - Paseo Virtual 3D

## Resumen
Este proyecto es un paseo virtual interactivo ambientado en los parques de estilo japonés, desarrollado en JavaScript utilizando Three.js (WebGL). Permite a los usuarios explorar un entorno 3D *low-poly*, simulando una visita inmersiva  con interacciones, iluminación dinámica y sonido, optimizado para una experiencia fluida desde el navegador web.

**Demo:** [koen-sakura.vercel.app](https://koen-sakura.vercel.app/)

## Características Principales
* Recorrido interactivo en primera persona.
* Controles de navegación responsivos (WASD/Joystick).
* Interacciones dinámicas con modelos.
* Interfaz de usuario intuitiva.
* Soporte multiplataforma (se ejecuta de forma nativa en navegadores web modernos).

## Palabras Clave
JavaScript, Three.js, WebGL, Vite, paseo virtual, 3D, gráficos por computadora, simulación, entorno interactivo, frontend.

## Requisitos Mínimos del Sistema
Dado que es una aplicación basada en WebGL, el rendimiento depende de utilizar un navegador web moderno con soporte para gráficos 3D.

**PC:**
* **SO:** Windows 10 / macOS 10.14 o superior.
* **Navegador:** Cualquier navegador moderno con soporte WebGL habilitado (Chrome, Firefox, Edge, Brave, Opera, etc.).
* **RAM:** 4 GB mínimo (Se recomiendan 8 GB).
* **Gráficos:** Intel UHD Graphics o GPU dedicada con soporte para WebGL 2.0.

**Móvil:**
* **SO:** Android 10.0+ / iOS 14.0+
* **Navegador:** Cualquier navegador móvil moderno compatible con WebGL (Chrome, Safari, Brave, Opera Mobile, etc.).
* **RAM:** 3 GB mínimo (Se recomienda 4GB o más).
* **Gráficos:** GPU móvil moderna.

## Cómo Clonar este Repositorio

Para obtener una copia local del proyecto, ejecuta en tu terminal:
```bash
git clone https://github.com/EduLovesHan/KoenSakura.git

```

Entra al directorio del proyecto:

```bash
cd KoenSakura

```

## Instalar dependencias

Primero, asegúrate de tener [Node.js](https://nodejs.org/) instalado en tu computadora.
Restaura las dependencias usando npm ejecutando:

```bash
npm install

```

## Compilación y Ejecución

Para iniciar el servidor local de desarrollo:

```bash
npm run dev

```

Haz clic en el enlace local que arroje la terminal (generalmente `http://localhost:5173/`)

Para compilar el proyecto:

```bash
npm run build

```
